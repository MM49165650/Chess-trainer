# Chessnut piece set

The twelve SVG files in this folder are the Chessnut chess pieces by Alexis
Luengas (<https://github.com/LexLuengas/chessnut-pieces>), copied unchanged from
the Lichess source code (<https://github.com/lichess-org/lila>, `public/piece/chessnut/`).

They are licensed under the Apache License, version 2.0. A copy of the licence,
taken from the original repository, is in `LICENSE.txt` in this folder.
