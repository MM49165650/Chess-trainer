# Fantasy piece set

The twelve SVG files in this folder are the Fantasy chess pieces by Maurizio
Monge (<https://github.com/maurimo/chess-art>), copied unchanged from the Lichess
source code (<https://github.com/lichess-org/lila>, `public/piece/fantasy/`).

They are licensed under the MIT licence. The copyright notice and the full
licence text, taken from the original repository, are in `LICENSE.txt` in this
folder, and must ship with the files.
