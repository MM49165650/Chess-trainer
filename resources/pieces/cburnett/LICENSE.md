# Cburnett piece set

The twelve SVG files in this folder are the Cburnett chess pieces by Colin M.L.
Burnett (<https://en.wikipedia.org/wiki/User:Cburnett>), copied unchanged from the
Lichess source code (<https://github.com/lichess-org/lila>, `public/piece/cburnett/`).
