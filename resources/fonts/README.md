# Fonts

The site's two typefaces, served from the site itself so that no visitor
request goes to a third party.

| --- | --- | --- |

| `instrument-sans/` | Instrument Sans, upright | 2022 The Instrument Sans Project Authors (<https://github.com/Instrument/instrument-sans>) |

in `OFL.txt` in each folder. The files are the Latin-subset variable fonts
published by the Fontsource project (<https://fontsource.org>), unchanged.

this repository.
