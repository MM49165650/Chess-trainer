# Sfx sound set

`Move.mp3`, `Move.ogg`, `Capture.mp3` and `Capture.ogg` are from the sfx sound set
by Enigmahack (<https://github.com/Enigmahack>), copied unchanged from the Lichess
source code (<https://github.com/lichess-org/lila>, `public/sound/sfx/`).

They are licensed under the GNU Affero General Public License, version 3 or any
later version: <https://www.gnu.org/licenses/agpl-3.0.html>

Lichess's licence file, `COPYING.md`, lists the set under `public/sounds/sfx`; it
spells the folder both ways, and this is the same folder.

These files are not covered by the GPL-3.0 licence that applies to the rest of
this repository.
